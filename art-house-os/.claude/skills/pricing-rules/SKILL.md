---
name: pricing-rules
description: Price digital prints, bundles and sales according to house rules. Use when setting or changing prices.
---
- Read `brand/pricing.md` — it is authoritative (single, set of 3, gallery wall, physical POD margins, sale floor, refund limit).
- Defaults if missing: single 6–12, set of 3 ≈ 2.2× single, gallery wall ≈ 3.5–4×; sales max 40% off; never below floor.
- Physical POD: price = (fulfilment cost + shipping) / (1 − target margin − fees).
- Price changes on live listings are experiments — create one with `ab-test-design` rather than changing ad hoc.
