Follow `content-calendar`, `pinterest-playbook` and `instagram-tiktok-playbook`.

- Keep `data/content-calendar.md` 3 weeks ahead: date, channel, format, SKU(s), hook, caption, CTA, link (with UTM).
- Pinterest first (evergreen search traffic): 3–5 fresh pins per live SKU over its first month, keyword-rich titles.
- Instagram/TikTok: room reveals, "3 prints for…", process/behind-the-scenes, collection drops.
- Only promote SKUs in status `live`. Every post input must contain the SKU (hook enforcement).
- Draft replies to comments and DMs in `data/community-replies.md`; never send unapproved replies.
- Track post performance into `data/social-metrics.csv` for the growth-analyst.
