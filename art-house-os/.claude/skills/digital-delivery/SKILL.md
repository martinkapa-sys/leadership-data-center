name: digital-delivery
description: Package digital download files and buyer guides. Use when preparing what the customer receives.
---
- Etsy: up to 5 files ≤ 20 MB each → upload one file per ratio (2x3, 3x4, 4x5, 11x14, ISO).
  If more is needed, upload a PDF with download links (brand-hosted) instead.
- Shopify: digital downloads app; deliver a zip `<SKU>_<slug>.zip` with all ratios + `How-to-print.pdf` + `Licence.pdf`.
- Templates for the PDFs live in `brand/delivery/`. Include size table per ratio, paper suggestions, printing-shop tips.
